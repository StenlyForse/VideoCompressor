## 1. Контекст и проблема

За игровую сессию NVIDIA App создаёт несколько записей. В v1 их приходится сжимать по одной: выбрать файл → «Сжать» → дождаться → следующий.

## 2. Цель

Выбрать сразу несколько видео и сжать их одним нажатием с **одинаковыми настройками для всех файлов**.

## 3. Не-цели

- Свои настройки для каждого файла.
- Параллельное сжатие нескольких файлов (одновременно идёт только один — так быстрее для видеокарты и предсказуемее по времени).
- Добавление целой папки с подпапками; сохранение очереди между запусками.

## 4. Пользовательские сценарии

### US-1. Сжать несколько файлов (P1)

**Критерии приёмки:**
1. В диалоге выбора можно отметить несколько файлов; перетаскивание нескольких файлов добавляет их все.
2. Файлы показываются списком: имя, параметры (разрешение · FPS · длительность · размер) и состояние.
3. Файлы можно добавлять к уже выбранным и убирать из списка до начала сжатия; есть «Очистить список».
4. Один набор настроек (степень сжатия или целевой размер, формат, кодировщик, разрешение, FPS) применяется ко всем файлам.
5. «Сжать» обрабатывает файлы по очереди, сверху вниз.
6. Видно состояние каждого файла: «Ожидает», «Сжатие… 47%», «Готово: 190,5 → 38,5 МБ», «Ошибка: …», «Отменено», «Пропущен: …».
7. Видно общий прогресс очереди: «Файл 2 из 5», общий процент и оценка оставшегося времени.
8. По окончании — итог: сколько файлов сжато, общий размер до и после, сколько с ошибками.
9. Выбор одного файла работает как в v1 — это очередь из одного файла.

### US-2. Ошибка в одном файле не останавливает очередь (P1)

1. Если файл не является видео или сжатие упало, у этого файла показывается ошибка, а очередь продолжается со следующего.

### US-3. Остановить очередь (P1)

1. «Отмена» останавливает текущий файл (недописанный результат удаляется, как в v1) и все оставшиеся; уже сжатые файлы сохраняются.
2. Закрытие окна во время очереди — подтверждение, как в v1.

### US-4. Результат не стал меньше (P2)

1. В очереди не задаются вопросы на каждый файл. Если результат не меньше исходника, он удаляется автоматически, а у файла — состояние «Пропущен: сжатый файл не меньше исходного».

## 5. Функциональные требования

- **FR-001** Результат каждого файла сохраняется рядом с его исходником как `<имя>_compressed.mp4` с правилами v1 (без перезаписи, суффиксы `(1)`, `(2)`).
- **FR-002** Один и тот же файл нельзя добавить в очередь дважды.
- **FR-003** «Показать файл» у каждого готового файла открывает его в файловом менеджере.
- **FR-004** Размер списка не ограничен искусственно; интерфейс не тормозит при 50 файлах.

## 6. Критерии успеха

| ID | Критерий |
|----|----------|
| SC-001 | 3 записи NVIDIA App выбираются одним действием и сжимаются одним нажатием «Сжать». |
| SC-002 | Если среди файлов есть не-видео, остальные сжимаются, а у него видна понятная ошибка. |
| SC-003 | Отмена на втором файле из трёх: первый результат сохранён, второго нет, третий не начат. |
